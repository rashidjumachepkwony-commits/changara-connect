feat: initial commit - Changara Connect v1.0.0

Full-stack local marketplace and services platform for Changara, Teso North, Busia County, Kenya.

Stack: Node.js + Express + MongoDB + Mongoose + JWT + bcrypt + Multer
Frontend: HTML5 + CSS3 + Vanilla JS (no framework)
PWA: manifest.json + service-worker.js

Includes:
- Complete REST API (auth, businesses, products, jobs, rentals, notices, services, search, admin)
- 12 Mongoose models (User, Business, Product, Job, Rental, Notice, Advertisement, Favorite, Category, Inquiry, Report, Payment)
- Auth + admin middleware with role-based access
- Secure Multer uploads (JPG/JPEG/PNG/WEBP, size limits)
- Admin dashboard with pending approvals and analytics
- Mobile-first responsive frontend (360px - 1024px+)
- PWA installable on Android
- Seed scripts for demo data and first admin
- .env.example with all required variables

Architecture-ready for future: M-Pesa payments, SMS/WhatsApp notifications, Firebase push, Google Maps, reviews, location search
